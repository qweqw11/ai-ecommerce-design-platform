V1 场景化任务主链路

把电商高频任务封装成可执行、可导出、可复用的标准流程

文档要求的核心不是复杂参数，而是让大众商家能围绕“做什么”完成少量配置，最终获得稳定可交付结果。当前阶段优先收束三类高频场景。

主链路闭环

任务进入 -> 素材上传 -> 场景化配置 -> 一键生成 -> 结果选择/必要时修复 -> 导出交付 -> 归档复用

1任务进入

选择场景类型，明确输出目标与交付预期。

2上传素材

提交商品图，系统提示素材规范与主体要求。

3场景配置

用少量选择项完成输出比例、场景模板和风格配置。

4结果交付

支持结果选择、导出、归档和后续复用。

V1 三大首发场景

与文档一致，先聚焦三类高频、低门槛、结果可快速验收的场景。

▤

服饰 / 商品上新主图

满足新品上架、活动测款、日常经营中的主图生产需求。

◐

一键换背景 / 场景迁移

保留商品主体，替换高质感背景，快速适配不同投放场景。

□

转平铺 / 白底标准化

生成标准化商品展示图，支持货架、详情页和基础投放。

结果要求

平台需要关注首图成功率、主体保真、一次性可用率和导出率。

首图成功率高输出结果需稳定可用，减少重复生成。
主体保真强商品主体、结构和材质需要尽量保持真实。
一次性可用优先系统要减少试错，不依赖复杂 prompt。
导出交付必备结果可直接下载并归档到素材库复用。
