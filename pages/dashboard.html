平台总览 / 版本节奏

从场景化任务出发，逐步走向智能助手与 LoRA 资产化

根据总 PRD，平台应先完成 V1 的场景化任务主链路，再进入 V2 智能助手效率增强，最后在 V3 承接 LoRA 一致性资产沉淀。控制台需要把这条版本路径讲清楚。

平台核心能力

平台围绕电商视觉生产需求，形成三层主能力结构。

✦

场景化任务主链路

面向大众商家的标准化交付路径，支持上传、配置、生成、导出、归档复用。

⌁

智能助手

承接任务前后高频轻处理需求，以快捷动作为主、低频对话为辅。

◇

LoRA 训练与资产化

面向高价值用户的一致性资产能力，沉淀固定模特、商品主体与品牌风格。

版本节奏

当前平台处于 V1 阶段，后续逐步扩展到 V2 / V3。

V1 场景化任务

优先验证大大众商家是否能通过低门槛流程完成一次稳定交付，核心是“快、稳、可导出”。

V2 智能助手

在任务前后提供抠图、清理背景、增强清晰度等高频轻处理，降低二次处理成本。

V3 LoRA 资产化

把固定主体、固定模特、固定品牌风格沉淀为可训练、可验收、可复用的资产。
